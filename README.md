# RTX 5090 Scam Mode

Притворяется, что у тебя в компе стоит **NVIDIA GeForce RTX 5090**, а не то, что на самом деле.

Сделан для троллинга друзей. Ничего не скачивает, не отправляет и не шифрует — просто
показывает системе другое имя видеокарты и другой объём видеопамяти.

> ⚠️ Инструмент меняет системный реестр и файлы драйверов. Используй на свой страх и риск.
> Всегда делай бэкап (скрипт делает это сам) и держи под рукой `2_ОТКАТ.cmd`.

---

## Что где срабатывает

Windows берёт название видеокарты из нескольких независимых источников, поэтому
одной правки недостаточно. Проект закрывает четыре поверхности из пяти:

| Поверхность | Статус | Чем сделано |
|---|---|---|
| Диспетчер устройств | ✅ | реестр, ключ `Enum\PCI` |
| `dxdiag` | ✅ | реестр, ключ `Enum\PCI` |
| Параметры → Система → О системе | ✅ | реестр, ключ `Enum\PCI` |
| Свойства видеоадаптера, объём VRAM (24 ГБ) | ✅ | реестр, `Class` + INF |
| **Диспетчер задач** | ❌ | читает DXGI напрямую из драйвера |
| `nvidia-smi`, GPU-Z, HWiNFO, Afterburner | ❌ | читают напрямую с карты |
| Панель управления NVIDIA | ❌ | читает напрямую с карты |
| Любой бенчмарк (3DMark и т.п.) | ❌ | реально считает FPS |

Диспетчер задач и `nvidia-smi` берут описание адаптера через **DXGI → NVAPI → драйвер**,
минуя реестр вообще. Реестр на них не влияет принципиально.

## Быстрый старт

1. Запусти **`1_ПОСТАВИТЬ_5090.cmd`** → согласись с UAC → дождись `Oshibok: 0`
2. **Перезагрузи компьютер** (это обязательно, см. «Грабли» ниже)
3. Проверь результат: **`3_ПРОВЕРИТЬ.cmd`**

Откатить: **`2_ОТКАТ.cmd`** + перезагрузка.

Другой объём памяти:

```cmd
powershell -ExecutionPolicy Bypass -File apply.ps1 -VramGB 16
```

Другое имя:

```cmd
powershell -ExecutionPolicy Bypass -File apply.ps1 -GpuName "NVIDIA GeForce RTX 4090"
```

## Как это устроено

Имя видеокарты в Windows лежит сразу в трёх местах, и правятся все три:

**1. Ключ класса драйвера** — `HKLM\SYSTEM\CurrentControlSet\Control\Class\{4d36e968-e325-11ce-bfc1-08002be10318}\0000`

```
DriverDesc                            = NVIDIA GeForce RTX 5090
HardwareInformation.AdapterString     = NVIDIA GeForce RTX 5090
HardwareInformation.ChipType          = NVIDIA GeForce RTX 5090
HardwareInformation.qwMemorySize       = 25769803776   (24 ГБ)
HardwareInformation.MemorySize         = 0xfff00000
```

Обрати внимание: значения лежат **плоскими именами прямо в ключе**, а не в подключе
`HardwareInformation\`. Это самая неприятная ловушка проекта — см. «Грабли».

**2. Ключ Enum** — `HKLM\SYSTEM\CurrentControlSet\Enum\PCI\VEN_10DE&DEV_2187&SUBSYS_...\<instance>`

```
DeviceDesc = @oem4.inf,%nvidia_dev.2187.8d95.1462%;NVIDIA GeForce RTX 5090
```

Именно отсюда берут имя Диспетчер устройств, dxdiag, WMI и «О системе».
Формат: `@<файл-inf>,<токен>;<текст для показа>`. Ведущий `@` обязателен — он
помечает значение как ссылку на INF.

Эти ключи защищены: писать в них может только SYSTEM, поэтому скрипт сначала
снимает ACL через `SetAccessRuleProtection`.

**3. INF-файл драйвера** — `C:\Windows\INF\<oemN>.inf`, секция `[Strings]`

```
NVIDIA_DEV.2187.8D95.1462 = "NVIDIA GeForce RTX 5090"
```

Нужно, чтобы имя не вернулось к оригиналу при переустановке или обновлении
драйвера — Windows перечитывает строку из INF.

## Грабли, на которые наступил автор

Если будешь делать что-то подобное — вот грабли, стоившие основной времени:

**1. Данные о видеокарте лежат в плоских именах, а не в подключе.**
Первая версия писала в `...\0000\HardwareInformation\AdapterString` и ничего не
менялось. Настоящие значения — `...\0000\HardwareInformation.AdapterString`,
плоским именем в самом ключе `0000`.

**2. `0xFFFFFFFF` в PowerShell 5.1 — это Int32 −1, а не 4294967295.**

```powershell
[uint32](($Bytes - 0x100000) -band 0xFFFFFFFF)   # падает: 25768755200 не влезает
[uint32](($Bytes - 0x100000) % [long]4294967296) # работает
```

**3. Обрезать VRAM надо по модулю, а не по `-band`.**
Реальные драйверы пишут `MemorySize = размер − 1 МБ`, обрезанный до 32 бит:
для 4 ГБ это `0xfff00000`, для 24 ГБ — тоже `0xfff00000` (в `qwMemorySize` при этом
лежит полное значение).

**4. Реестр без перезагрузки не работает.**
Windows читает эти значения только при инициализации видеоустройства. Запустил
скрипт, посмотрел Диспетчер устройств — старое имя из кэша. Нужна перезагрузка
(или отключить/включить устройство).

**5. MSVC не умеет PE-форвардеры в `.def`.**
Синтаксис `exportName = otherDll.exportName` приводит к `LNK2001`, а
самоимпорты (`dxgi.dll` импортирует сам себя) ломаются на уровне загрузчика.
Приходится реализовывать все экспорты вручную.

**6. vtable у адаптера NVIDIA нестандартная.**
Ручной вызов `GetDesc`/`GetDesc1` по слотам 4 и 6 роняет процесс с `0xC0000005`,
хотя вызов через компилятор работает. Патчить vtable «по индексу» нельзя.

## Эксперимент: DXGI-прокси

В `src/` лежит `dxgi_proxy.cpp` — прокси-DLL поверх `System32\dxgi.dll`, которая
должна была обмануть и Диспетчер задач.

**Статус: не работает.** Прокси собирается, экспортирует все 20 функций с
исходными ординалами, зависит только от `KERNEL32.dll` — но подмена описания
адаптера не удалась из-за п. 6 в «Граблях» выше. Планировалась замена на
COM-обёртку с собственным vtable, работа не доделана.

Не устанавливай её в `System32`. Нужна корректная реализация, а не то, что лежит
в репозитории.

### Сборка нативных частей

Нужны Visual Studio 2022 / Build Tools с MSVC v143 и Windows SDK:

```powershell
cd src
.\build.ps1
```

Соберёт `gpuinfo.exe` (диагностика через DXGI), `test_dxgi.exe` (стенд) и `dxgi.dll`.

## Откат

`2_ОТКАТ.cmd` восстанавливает всё из `backup/`:

- ключи класса и `Control\Video` — из `.reg`
- ключи `Enum` — из `.reg`
- INF-драйвер — из `oem4.inf.bak`

Идёт по всем бэкапам, а не только по последнему. После отката — перезагрузка.

---

## Что сломалось, а что нет

Скрипт ничего не ломает: подменяются только текстовые значения в реестре и одна
строка в INF. Производительность, драйвер и работа видеокарты не затрагиваются.
Имя устройства в Диспетчере задач и `nvidia-smi` останется настоящим — это
принципиальное ограничение, а не недоделка скрипта.

Обновление драйвера NVIDIA перезапишет INF и вернёт настоящее имя.
